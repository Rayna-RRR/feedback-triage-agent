Decision rules

工作台如何形成结论

  1. 01校验输入

    保留来源、时间、原文和字段缺失记录，不静默补造数据。

  2. 02聚合问题

    多条相似反馈进入一个问题簇，一条多意图反馈可以保留多个判断。

  3. 03比较变化

    同时查看数量和反馈占比，区分新增、加重、稳定、缓解与证据不足。

  4. 04人工复核

    高风险、低置信度和规则冲突问题先由人确认，再进入负责人摘要。

  5. 05跟踪结果

    记录负责人、动作和结果，下个窗口继续验证问题是否改善。
